## 概要

この機能では、以下の3つの操作が可能です：

| 操作 | 説明 |
|------|------|
| **取得** | カラーミーから商品情報を取得してシートに反映 |
| **更新** | シートで編集した内容をカラーミーに反映 |
| **新規登録** | シートに入力した新商品をカラーミーに登録 |

---

## シートの列構成

「カラーミー商品管理」シートの列構成は以下の通りです。

### 基本情報（A〜J列）- 入力項目

| 列 | 項目名 | 説明 |
|----|--------|------|
| A | 商品ID | カラーミーの商品ID（新規登録時は空欄） |
| B | 商品名 | 商品の名前（必須） |
| C | 商品URL | カラーミー上の商品ページURL |
| D | 販売価格 | 販売価格（必須） |
| E | 原価 | 仕入れ原価 |
| F | 在庫数 | 現在の在庫数 |
| G | 販売ステータス | 販売中/販売停止 |
| H | 掲載ステータス | 掲載/非掲載 |
| I | 外部価格URL | 価格比較用の外部URL |
| J | 外部価格抽出ルール | 価格抽出のCSSセレクタ等 |

### 計算・履歴（K〜AA列）- 自動計算

| 列 | 項目名 | 説明 |
|----|--------|------|
| K-S | 自動計算結果 | 利益率、価格差等 |
| T-W | ユーザー計算式 | カスタム計算用 |
| X | 最終更新 | 価格チェック日時 |
| Y-AA | 外部価格履歴 | 過去の価格推移 |

### 同期設定・詳細情報（AC〜BC列）- 新機能

※G列（固定マージン価格）追加により、旧AB列以降が1列ずれています

| 列 | 項目名 | 説明 |
|----|--------|------|
| **AC** | **同期モード** | `ドラフト作成` / `取得のみ` / `更新` / `新規登録` / `なし` |
| AD | 型番 | 商品の型番・モデル番号 |
| AE | カテゴリーID | 大カテゴリーのID（必須：新規登録時） |
| AF | サブカテゴリーID | 小カテゴリーのID |
| AG | グループID | グループID（カンマ区切りで複数指定可） |
| AH | 定価 | 定価（メーカー希望小売価格） |
| AI | 会員価格 | 会員向け特別価格 |
| AJ | 個別送料 | 商品個別の送料設定 |
| AK | 在庫管理 | `する` / `しない` |
| AL | 売切れ表示 | `表示` / `非表示` |
| AM | 適正在庫数 | 残り僅か表示の閾値 |
| AN | 最小購入数 | 一度に購入できる最小数量 |
| AO | 最大購入数 | 一度に購入できる最大数量（0=無制限） |
| AP | 商品説明 | 商品の詳細説明（HTML可） |
| AQ | 簡易説明 | 商品の短い説明 |
| AR〜BA | 画像URL1〜10 | 商品画像のURL（最大10枚） |
| BB | 同期ステータス | 処理結果（成功/エラー: xxx） |
| BC | 同期日時 | 最後に同期した日時 |

## 同期モードの設定

**AC列「同期モード」** に以下のいずれかを入力してください：

| 値 | 動作 |
|----|------|
| `ドラフト作成` | 取得元URLから商品情報をスクレイピングしてシートに反映します。カラーミーには登録しません。 |
| `取得のみ` | カラーミーから最新情報を取得してシートに反映します。シートの内容は上書きされます。 |
| `更新` | シートの内容でカラーミーの商品情報を更新します。 |
| `新規登録` | 新しい商品としてカラーミーに登録します（商品IDが空欄の場合のみ有効）。 |
| `なし` または 空欄 | この商品は同期処理の対象外になります。 |

### 設定例

```
行2: 商品ID=空欄,  同期モード=ドラフト作成 → 取得元URLから情報を取得（シートのみ）
行3: 商品ID=12345, 同期モード=取得のみ    → カラーミーから情報を取得
行4: 商品ID=12346, 同期モード=更新        → シートの内容でカラーミーを更新
行5: 商品ID=空欄,  同期モード=新規登録    → 新商品として登録
行6: 商品ID=12347, 同期モード=なし        → 何もしない
```

## コマンドの実行方法

### ドライランモード（テスト実行）

実際にカラーミーを更新せず、処理内容を確認できます。**初回は必ずこちらで確認してください。**

```bash
COLORME_DRY_RUN=true python -m src.main --sync-colorme
```

### 本番実行

実際にカラーミーの商品情報を更新します。

```bash
COLORME_DRY_RUN=false python -m src.main --sync-colorme
```

### 必要な環境変数

```bash
export SPREADSHEET_ID="あなたのスプレッドシートID"
export COLORME_ACCESS_TOKEN="カラーミーのアクセストークン"
```

## 各機能の詳細

### 1. 取得のみ（カラーミー → シート）

カラーミーから商品の全情報を取得し、シートのAD〜BA列に反映します。

**手順：**
1. 取得したい商品のAC列に `取得のみ` と入力
2. コマンドを実行
3. AD〜BA列に最新情報が反映される
4. BB列に「成功」、BC列に日時が記録される

**対象フィールド：**
- 型番、カテゴリー、グループ
- 各種価格（定価、会員価格）
- 在庫管理設定
- 商品説明（HTML）
- 画像URL

### 2. 更新（シート → カラーミー）

シートで編集した内容をカラーミーに反映します。

**手順：**
1. 更新したい商品のAC列に `更新` と入力
2. AD〜BA列の内容を編集
3. コマンドを実行
4. カラーミーの商品情報が更新される
5. BB列に「成功」、BC列に日時が記録される

**更新可能なフィールド：**
- 商品名（B列）
- 販売価格（D列）
- 原価（E列）
- 在庫数（F列）
- 販売ステータス（G列）
- 掲載ステータス（H列）
- 型番〜画像URL10（AD〜BA列）

### 3. 新規登録（シート → カラーミー）

シートに入力した新商品をカラーミーに登録します。

**手順：**
1. 新しい行に商品情報を入力（A列の商品IDは空欄にする）
2. AC列に `新規登録` と入力
3. コマンドを実行
4. カラーミーに商品が登録される
5. A列に新しい商品IDが自動で入力される
6. BB列に「成功」、BC列に日時が記録される

---

## 新規商品の登録

### 必須項目

新規登録時は以下の項目が必須です：

| 列 | 項目名 | 備考 |
|----|--------|------|
| B | 商品名 | 空欄不可 |
| D | 販売価格 | 0以上の整数 |
| AE | カテゴリーID | カラーミー管理画面で確認 |

### カテゴリーIDの確認方法

1. カラーミー管理画面にログイン
2. 「商品管理」→「カテゴリー」を開く
3. 各カテゴリーのIDを確認（URLまたは編集画面で確認可能）

### 登録例

```
B列（商品名）: 2024年 イギリス ブリタニア 1オンス銀貨
D列（販売価格）: 12800
AE列（カテゴリーID）: 123
AF列（サブカテゴリーID）: 456  ※任意
AP列（商品説明）: <p>純銀製の美しいブリタニア銀貨です。</p>
AC列（同期モード）: 新規登録
```

## 画像のアップロード

### メイン画像

AR列（画像URL1）に画像のURLを入力すると、自動的にダウンロードしてカラーミーにアップロードします。

```
AR列（画像URL1）: https://example.com/images/coin-front.jpg
```

### 追加画像（最大9枚）

AS〜BA列（画像URL2〜10）に追加画像のURLを入力できます。

```
AS列（画像URL2）: https://example.com/images/coin-back.jpg
AT列（画像URL3）: https://example.com/images/coin-case.jpg
```

### 対応画像形式

- JPEG (.jpg, .jpeg)
- PNG (.png)
- GIF (.gif)

### 注意点

- 画像URLは公開されている必要があります（認証が必要なURLは不可）
- 大きな画像は自動的にリサイズされます
- アップロード済みの画像URLは変更されません

## エラーの確認方法

処理結果はBB列（同期ステータス）に記録されます。

| ステータス | 説明 |
|-----------|------|
| `成功` | 処理が正常に完了 |
| `エラー: xxx` | エラーが発生（xxx にエラー内容） |
| `スキップ: xxx` | 処理がスキップされた理由 |

### よくあるエラー

| エラー | 原因 | 対処法 |
|-------|------|--------|
| `商品名が空です` | B列が空欄 | 商品名を入力 |
| `販売価格が無効です` | D列が空欄または不正 | 有効な価格を入力 |
| `カテゴリーIDが必須です` | AD列が空欄（新規登録時） | カテゴリーIDを入力 |
| `商品が見つかりません` | 商品IDが無効 | 正しい商品IDを確認 |
| `APIエラー: 401` | 認証エラー | アクセストークンを確認 |
| `APIエラー: 429` | レート制限 | しばらく待ってから再実行 |

## 注意事項

### ドライランモードについて

- 初めて実行する際は必ず `COLORME_DRY_RUN=true` で確認してください
- ドライランでは実際の更新・登録は行われず、ログのみ出力されます

### API制限

- カラーミーAPIには **120リクエスト/分** の制限があります
- 大量の商品を処理する場合は自動的に待機します

### データの上書き

- 「取得のみ」モードではシートの内容が上書きされます
- 重要な編集内容がある場合は事前にバックアップしてください

### 同期モードの優先順位

1. `新規登録` - 商品IDが空欄の場合のみ有効
2. `更新` - 商品IDが必要
3. `取得のみ` - 商品IDが必要
4. `なし`/空欄 - スキップ

### 画像について

- 画像のアップロードは「更新」または「新規登録」モードでのみ実行されます
- 既存の画像を削除するには、カラーミー管理画面から直接操作してください

## トラブルシューティング

### 「スプレッドシートに接続できません」

- `SPREADSHEET_ID` 環境変数を確認
- Google認証情報（ADCまたはサービスアカウント）を確認

### 「カラーミーAPIトークンが設定されていません」

- `COLORME_ACCESS_TOKEN` 環境変数を確認

### 「ヘッダーが見つかりません」

- シートの1行目にヘッダーが存在するか確認
- 初回実行時にAC〜BC列のヘッダーは自動作成されます

### 処理が途中で止まる

- ネットワーク接続を確認
- カラーミーのサービス状態を確認
- エラーログを確認して原因を特定
